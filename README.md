# Random Wikipedia article

A site that you click a button and shows a random wikipedia article

## Features

- A button that shows a random article
- fun facts about history and wikipedia
- favorite list
- history list
  
## Tech Stack

- HTML
- CSS
- JavaScript

## Live Website

https://davidperyro-stack.github.io/random-wikipedia-article/
